    2. Project 1：形状特征与傅里叶描述子核心代码

    根据实验要求，我们需要实现傅里叶描述子（Fourier Descriptors）的提取 ，逐渐增加 \(P\) 值并观察重建轮廓的变化 。 以下是完整的 Python 实现代码，你可以直接在你的 uv 环境或 Jupyter Notebook 中运行：

    import scipy.io as sio
import numpy as np
import cv2
import matplotlib.pyplot as plt

def get_fourier_descriptors(contour):
    """
    计算轮廓的傅里叶描述子
    """
    # 1. 将 (x, y) 坐标复数化: s = x + iy
    # 假设 contour 的 shape 是 (N, 1, 2) —— 这是 cv2.findContours 的标准输出
    complex_contour = contour[:, 0, 0] + 1j * contour[:, 0, 1]

    # 2. 进行一维离散傅里叶变换 (FFT)
    descriptors = np.fft.fft(complex_contour)
    return descriptors

def reconstruct_contour(descriptors, P, num_points):
    """
    保留 P 个描述子并进行轮廓重建
    """
    # 将零频分量（直流分量）移到数组中心，方便对称截断
    descriptors_shifted = np.fft.fftshift(descriptors)

    # 创建一个全零的频域数组
    truncated_descriptors = np.zeros_like(descriptors_shifted)

    # 计算中心点，并保留中心周围的 P 个低频分量
    center = len(descriptors_shifted) // 2
    half_P = P // 2

    # 防止 P 超过总点数
    start_idx = max(0, center - half_P)
    end_idx = min(len(descriptors_shifted), center + half_P)

    truncated_descriptors[start_idx:end_idx] = descriptors_shifted[start_idx:end_idx]

    # 逆平移并进行逆傅里叶变换 (IFFT)
    reconstructed_complex = np.fft.ifft(np.fft.ifftshift(truncated_descriptors))

    # 提取实部和虚部作为新的 x, y 坐标
    reconstructed_contour = np.zeros((num_points, 1, 2), dtype=np.int32)
    reconstructed_contour[:, 0, 0] = np.real(reconstructed_complex).astype(np.int32)
    reconstructed_contour[:, 0, 1] = np.imag(reconstructed_complex).astype(np.int32)

    return reconstructed_contour

    3. P 值与形状保真度的关系探讨 (Discuss)

    实验的最后要求讨论描述子数量 \(P\) 与形状保真度（Fidelity）之间的关系 。为了让你更直观地理解这个数学过程，我为你构建了一个交互式的傅里叶描述子模拟器。你可以亲自拖动滑块，观察 \(P\) 值变化时轮廓发生的动态变化。

    讨论要点总结（你可以写入你的实验报告）：

    1. 低频决定宏观形状：当 \(P\) 非常小（例如 2 或 4）时，重建的形状表现为基本的几何图形（如圆形或椭圆）。这是因为只保留了低频分量，这些分量决定了轮廓的整体位置和基础伸展方向。
    2. 高频决定边缘细节：随着 \(P\) 值的增加，重建轮廓开始捕捉到肿瘤边缘的“锯齿”、“突起”和“凹陷”。这些是不规则肿瘤（如胶质瘤 glioma）的重要临床特征。

    Project 2 核心实验原理深度解析

    在动手写代码前，我们需要彻底搞懂这四个一阶统计特征的数学含义，以及为什么要“用迭代均值滤波来模拟高斯模糊”。

    1. 肿瘤质心与 ROI 提取

    图像的质心是通过图像矩（Image Moments）来计算的。对于肿瘤的二值化掩膜 \(M(x,y)\)，其零阶矩 \(M_{00}\) 表示肿瘤的总面积，一阶矩 \(M_{10}\) 和 \(M_{01}\) 分别表示 \(x\) 和 \(y\) 方向上的灰度加权空间位置。 质心坐标 \((\bar{x}, \bar{y})\) 的计算公式为：

    $$ \bar{x} = \frac{M_{10}}{M_{00}}, \quad \bar{y} = \frac{M_{01}}{M_{00}} $$ 找到质心后，我们以该点为中心切取一个固定大小的矩形窗口（例如 \(120 \times 120\) 像素），该窗口即为我们的 ROI，它能让我们专注于肿瘤及其紧密邻域的纹理 。

    2. 四大一阶直方图指标

    一阶统计特征不考虑像素之间的空间相对位置，只关注区域内像素灰度值的概率分布（即直方图）。设 \(p(z_i)\) 为灰度级 \(z_i\) 在区域内出现的概率，\(L\) 为总灰度级数（通常归一化为 256 级） ：

    • 均值 (Mean, μ)：\(\mu = \sum_{i=0}^{L-1} z_i p(z_i)\)。反映区域的平均亮度 。
    • 方差 (Variance, σ2)：\(\sigma^2 = \sum_{i=0}^{L-1} (z_i - \mu)^2 p(z_i)\)。反映灰度对比度。方差越大，说明肿瘤内部的明暗交错越剧烈，异质性（Heterogeneity）越高 。
    • 一致性 (Uniformity, U)：\(U = \sum_{i=0}^{L-1} p(z_i)^2\)。当图像中所有像素灰度值完全相同时，一致性达到最大值 1。它衡量的是直方图的平坦或集中程度 。
    • 熵 (Entropy, H)：\(H = -\sum_{i=0}^{L-1} p(z_i) \log_2 p(z_i)\)。衡量图像灰度分布的随机性或混乱度。纹理越复杂、细节越丰富的区域，熵值越大 。

    3. 为什么“迭代 3x3 均值滤波”能模拟“高斯模糊”？

    根据概率论中的中心极限定理（Central Limit Theorem），多个独立同分布的随机变量相加，其最终分布会趋向于正态分布。 在图像处理中，\(3 \times 3\) 的均值滤波器本质上是一个矩形窗口的均匀分布。当我们对一张图像连续、重复地进行多次均值滤波时，其等效的卷积核形状会从最初的方框逐步平滑，最终在数学上无限逼近于高斯核。 这种方法在工业界常用于快速实现高斯模糊 。

    第二步：核心实验原理（量化与二阶统计）

    PPT 里提到了一个非常关键的词：quantized（量化）。

    • 为什么要量化？ 原图有 256 个灰度级，如果直接算 GLCM，生成的矩阵将是 \(256 \times 256\)，不仅极其稀疏（大部分是 0），而且计算非常缓慢，反而掩盖了纹理特征。

    2. 为什么是一条明亮的对角线？
